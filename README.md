# Roult — Landing Page

Sitio corporativo de Roult (desarrollo de software a medida + suite de productos SaaS por suscripción).

## Estructura

- `index.html` — la landing.
- `privacidad.html` — política de privacidad.
- `productos/` — capturas usadas por la landing (Gastify).
- `og.jpg` — imagen de Open Graph.

## Despliegue

Sitio estático, sin build. Se despliega directo desde la raíz del repo (Vercel u otro hosting estático).
